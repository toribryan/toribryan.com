A calendar is a month grid for picking one day or a range. It works on its
own on a page, and it's the grid inside Date picker and Date range picker.
In range mode the range is drawn as one bar per week, and while the second
day is chosen it previews under the pointer or the keyboard. It has the
whole keyboard model of a date grid, bounds and rules for the days that
can't be picked, a week that starts on Sunday or Monday, and names in any
locale.

<ExhibitCode label="Usage">

```tsx
import { Calendar } from "@/components/ui/calendar"

export function Availability() {
  const [range, setRange] = useState<{ from: Date; to?: Date } | null>(null)
  return (
    <Calendar
      mode="range"
      months={2}
      value={range}
      onChange={setRange}
      minDate={new Date()}
    />
  )
}
```

In range mode `onChange` fires after each pick: with only `from` after the
first, with both after the second. Wait for `to` before you act on it.

<ExhibitCode label="Props">

| Prop             | Type                             | Default                             | Description                                                                                                                       |
| ---------------- | -------------------------------- | ----------------------------------- | --------------------------------------------------------------------------------------------------------------------------------- |
| `mode`           | `"single" \| "range"`            | `"single"`                          | `single` picks one day; `range` picks a start and an end.                                                                         |
| `value`          | `Date \| DraftRange \| null`     |                                     | The selected day or range, when you control it. In a range, `to` is missing between the picks.                                    |
| `defaultValue`   | `Date \| DraftRange \| null`     |                                     | The selection at first, when the calendar keeps its own state.                                                                    |
| `onChange`       | `(value) => void`                |                                     | Called with the day picked, or after each pick of a range.                                                                        |
| `type`           | `"paged" \| "scroll" \| "month"` | `"paged"`                           | `paged` shows whole months with arrows; `scroll` stacks a year either side in one scroll; `month` is a full-page month of events. |
| `events`         | `CalendarEvent[]`                |                                     | With `type="month"`, the events to show, each on the day it starts.                                                               |
| `onEventClick`   | `(event: CalendarEvent) => void` |                                     | With `type="month"`, makes the events in the selected day's list buttons.                                                         |
| `labels`         | `Partial<CalendarLabels>`        |                                     | The words it writes for itself, for translation: Today, +N more, No events, All day.                                              |
| `children`       | `ReactNode`                      |                                     | With `type="month"`, actions at the end of the header.                                                                            |
| `size`           | `"default" \| "lg"`              | `"default"`                         | Day cells at 36 pixels, or 44 for touch.                                                                                          |
| `months`         | `1 \| 2`                         | `1`                                 | Months shown side by side in the paged type. They stack where there isn't room.                                                   |
| `month`          | `Date`                           |                                     | The first month shown, when you control it.                                                                                       |
| `defaultMonth`   | `Date`                           | The selection's month, then today's | The first month shown at first.                                                                                                   |
| `onMonthChange`  | `(month: Date) => void`          |                                     | Called with the first month shown when it changes.                                                                                |
| `minDate`        | `Date \| null`                   |                                     | The earliest day that can be picked.                                                                                              |
| `maxDate`        | `Date \| null`                   |                                     | The latest day that can be picked.                                                                                                |
| `isDateDisabled` | `(date: Date) => boolean`        |                                     | Return true for a day that can't be picked, such as a weekend.                                                                    |
| `weekStartsOn`   | `0 \| 1`                         | `0`                                 | The first column: 0 for Sunday, 1 for Monday.                                                                                     |
| `locale`         | `string`                         | `"en-US"`                           | A BCP 47 locale for month and weekday names and day numbers.                                                                      |

It also takes every prop of a `div`, except `children`.


## Examples

### Range

Two months side by side. The first pick sets the start, and the bar follows
the pointer until the second; picking an earlier day orders the range. Where
there isn't room for two months side by side, they stack; the days never
shrink below their size.

### On a phone

`type="scroll"` stacks a year either side of the selection in one vertical
scroll, under a weekday header that stays put. Use it with `size="lg"`,
which makes each day 44 pixels, in a drawer on a phone. Date picker's
drawer, which it opens below the `sm` breakpoint, is built this way.

## Month view

`type="month"` is a full-page month of events: the month and its date span as
the title, Previous, Today and Next, and a grid of day cells that fills its
parent. Each cell shows its day and the first two events as cards, then a
count of the rest. Picking a day lists all its events, beside the grid from
1024 pixels wide and under it below that. It picks one day, with the same
`value`, `onChange`, `month` and bounds as the other types.

### With actions

Children go at the end of the header, for actions such as search and a new
event. The other types ignore children.

<Exhibit
  of="calendar.MonthWithActions"
  title="With actions"
  description="Search and New event, passed in as children."
>
<ExhibitCode>

```tsx
type CalendarEvent = {
  id: string
  title: string
  start: Date // the day it shows on
  end?: Date // same day
  allDay?: boolean
}
;<Calendar type="month" events={events}>
  <Button size="sm" onClick={newEvent}>
    <PlusIcon data-icon="inline-start" />
    New event
  </Button>
</Calendar>
```

</ExhibitCode>
</Exhibit>

The month view fills its parent, so give the parent a height. It picks one
day: with `mode="range"` it draws the paged type and warns in the console.
Its English words (Today, +N more, No events, All day) come from `labels`.

## Anatomy

Previous and next buttons over the months on screen, each a title and a grid
of week rows. In range mode a bar sits behind each week the range crosses.

<Exhibit of="calendar.Anatomy" title="The calendar" description="A range in one month.">
<ExhibitCode label="Structure">

```text
Calendar                calendar               (paged or scroll)
├─ previous             calendar-previous      (paged only)
├─ next                 calendar-next          (paged only)
├─ months               calendar-months        (paged only; slides when the page turns)
│  └─ month             calendar-month
│     ├─ title          calendar-month-title
│     └─ grid           calendar-grid          (labelled by the title, one row per week)
│        ├─ range bar   calendar-range-bar     (one per week row the range crosses)
│        └─ day         calendar-day           (a button named with the full date)
├─ weekdays             calendar-weekdays      (scroll only; stays above the scroll)
└─ scroll               calendar-scroll        (scroll only; holds the stacked months)
```

</ExhibitCode>
