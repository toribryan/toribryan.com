Says whether someone is present, away or offline, told apart by shape as
well as colour.

<Exhibit
  of="status-dot.Default"
  title="Status dot"
  description="Present, at the default size."
>
<ExhibitCode label="Install">

```bash
npx shadcn@latest add https://fibo.toribryan.com/r/status-dot.json
```

It installs `class-variance-authority`, and adds the `success` and `warning`
tokens if your theme lacks them.

</ExhibitCode>
<ExhibitCode label="Usage">

```tsx
import { Avatar, AvatarFallback, AvatarImage } from "@/components/ui/avatar"
import { StatusDot } from "@/components/ui/status-dot"

export function Member() {
  return (
    <Avatar>
      <AvatarImage src="/ana.jpg" alt="Ana Ruiz" />
      <AvatarFallback>AR</AvatarFallback>
      <StatusDot status="away" />
    </Avatar>
  )
}
```

Let the dot say the status, or the text beside it, never both: pass
`label={null}` when the words are already on screen.

</ExhibitCode>
<ExhibitCode label="Props">

| Prop      | Type                                | Default     | Description                                                                                                |
| --------- | ----------------------------------- | ----------- | ---------------------------------------------------------------------------------------------------------- |
| `status`  | `"present" \| "away" \| "offline"`  |             | A dot, a crescent or a ring, so status reads without colour.                                               |
| `label`   | `string \| null`                    | The status  | The spoken status, for translation. Defaults to Present, Away or Offline; `null` makes the dot decorative. |
| `variant` | `"color" \| "mono"`                 | `"color"`   | Coloured with the `success`, `warning` and `muted-foreground` tokens, or drawn in the text colour.         |
| `size`    | `"xs" \| "sm" \| "default" \| "lg"` | `"default"` | 8, 10, 12 or 16 pixels. A host can size it too; Avatar matches it to its own size.                         |

It also takes every prop of a `span`, except `children`.

</ExhibitCode>
</Exhibit>

## Anatomy

A page-coloured disc with the mark on it, plus a visually hidden label.

<Exhibit of="status-dot.Anatomy" title="The dot" description="Away, drawn large.">
<ExhibitCode label="Structure">

```text
StatusDot               status-dot
├─ svg                  (hidden from screen readers)
│  ├─ disc              the page colour
│  └─ mark              a dot, a crescent or a ring
└─ label                (visually hidden, unless label is null)
```

</ExhibitCode>

## Accessibility

There's nothing to focus: the dot only reports, so it never enters the tab
order.

<UsageGuidelines
  guidelines={[
    "The status is in a visually hidden span, read after whatever comes before it: the photo's alt in an Avatar, the name in a Sticker avatar.",
