Reactions let people respond to content with an emoji in one tap. They sit
under a message or post as a row of pills, or float in a corner of the page.

<Exhibit
  of="reactions.InMessage"
  title="Reactions"
  description="Tap a pill to add or take back yours, or the smiley to pick another."
>
<ExhibitCode label="Install">

```bash
npx shadcn@latest add https://fibo.toribryan.com/r/reactions.json
```

It installs Base UI for the picker, plus the `--popover-overlay`,
`--primary-subtle`, `--ring-subtle` and `--particle-shadow` tokens. No animation library: the
burst and the pill motion use the Web Animations API.

</ExhibitCode>
<ExhibitCode label="Usage">

```tsx
import { Reactions } from "@/components/ui/reactions"

export function MessageReactions() {
  return (
    <Reactions
      defaultReactions={[
        { emoji: "\u{1F44D}", label: "Thumbs up", count: 5 },
        { emoji: "❤️", label: "Heart", count: 3, active: true },
      ]}
    />
  )
}
```

A reaction's `emoji` is its identity, so keep it unique. Its `label` is what
screen readers hear.

</ExhibitCode>
<ExhibitCode label="Props">

| Prop                | Type                                                           | Default             | Description                                                                            |
| ------------------- | -------------------------------------------------------------- | ------------------- | -------------------------------------------------------------------------------------- |
| `type`              | `"inline" \| "floating"`                                       | `"inline"`          | Pills under the content, or a bar pinned to a viewport corner.                         |
| `position`          | `"bottom-right" \| "bottom-left" \| "top-right" \| "top-left"` | `"bottom-right"`    | Viewport corner. Applies to the floating type only.                                    |
| `reactions`         | `Reaction[]`                                                   |                     | The reactions on the item. Pass it to control the state yourself.                      |
| `defaultReactions`  | `Reaction[]`                                                   | `[]`                | The starting reactions when uncontrolled.                                              |
| `choices`           | `Reaction[]`                                                   |                     | What the picker offers. Defaults to six common reactions plus any already on the item. |
| `onReactionsChange` | `(reactions: Reaction[]) => void`                              |                     | Fires with the whole new list after every change.                                      |
| `onReact`           | `(reaction: Reaction, active: boolean) => void`                |                     | Fires with the reaction that changed and whether it is now on.                         |
| `showCounts`        | `boolean`                                                      | `true`              | Show the count on each pill, or the total on the floating bar.                         |
| `particles`         | `number`                                                       | `7`                 | Emoji thrown up on each new reaction. `0` turns the burst off.                         |
| `triggerLabel`      | `string`                                                       | `"Add reaction"`    | Accessible name of the button that opens the picker.                                   |
| `panelLabel`        | `string`                                                       | `"Pick a reaction"` | Accessible name of the group of choices.                                               |
| `locale`            | `string`                                                       | `"en"`              | Locale for counts of a thousand and up, fixed so the server and browser render alike.  |

```ts
type Reaction = {
  emoji: string // its identity, so keep it unique
  label: string // what screen readers hear
  count?: number
  active?: boolean // the current person has reacted with it
}
```

</ExhibitCode>
</Exhibit>

## Anatomy

button. Your own reactions are tinted.

## Guidelines

<UsageGuidelines
  guidelines={[
    "Put the row right under the message, comment or post it responds to.",
    "Use the floating bar for a reaction to the whole page, such as the end of an article. One per page.",
    "Offer five or six choices at most. More turns a quick tap into a decision.",
    "Leave the choices at their six defaults unless your product has its own vocabulary. Anything already on the item is added to them.",
    "A reaction nobody holds any more disappears instead of lingering as a zero.",
    "Hide the counts where numbers would turn reactions into a contest.",
    <>
      Counts past a thousand shorten to 1.2K, so a busy post keeps its pills
      small. They shorten in English unless you pass <code>locale</code>, so the
      server and the browser render the same text.
    </>,
  ]}
/>

<Tip>
  Pass <code>reactions</code> and <code>onReactionsChange</code> to control the
  state from your data layer. Without them the component keeps its own state,
  seeded from <code>defaultReactions</code>.
</Tip>

## Accessibility

Every pill and the add button is a regular button, so the row works from the
keyboard in tab order.

| Key                                           | Does                                                    |
| --------------------------------------------- | ------------------------------------------------------- |
| <Kbd>Tab</Kbd>                                | Moves between the pills and the add button              |
| <Kbd>Space</Kbd> or <Kbd>↵</Kbd>              | Adds or takes back a reaction, or opens the picker      |
| <KbdGroup><Kbd>←</Kbd><Kbd>→</Kbd></KbdGroup> | Moves through the choices in the picker                 |
| <Kbd>Home</Kbd> or <Kbd>End</Kbd>             | Jumps to the first or last choice                       |
| <Kbd>Esc</Kbd>                                | Closes the picker and puts focus back on the add button |

<UsageGuidelines
  guidelines={[
    <>
      Each pill is a toggle button named by the reaction's label and count, such
      as "Heart, 3 reactions", with <code>aria-pressed</code> for whether you've
      reacted. The emoji itself is hidden from screen readers.
    </>,
    'A polite live region announces each change: "Added Heart", "Removed Heart". On the floating bar, with counts on, it adds the new total: "Added Heart, 13 reactions in total".',
    "With showCounts off, pills are named by their label alone, so screen readers hear what sighted users see.",
    "Choices you've already picked show as pressed in the picker too.",
    "Arrow keys, Home and End move through the choices. Escape closes the picker and returns focus to its trigger; tabbing away closes it too.",
    "Particles and pill motion switch off under prefers-reduced-motion.",

      Override <code>triggerLabel</code> and <code>panelLabel</code> when your
      product speaks another language.
    </>,
  ]}
/>
