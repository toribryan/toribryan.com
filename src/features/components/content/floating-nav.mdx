Floating nav is a pill of destinations that floats above the bottom of a phone
screen. The current item stretches to show its name, and the bar can step out
of the way while people read. It's the nav on this site when you open it on a
phone.

It installs `motion`, for the indicator and the slide, plus the
`--popover-overlay`, `--ring-subtle` and three `--glass-*` tokens.

<ExhibitCode label="Usage">

```tsx
import { BookmarkIcon, HouseIcon, UserIcon } from "lucide-react"

import { FloatingNav } from "@/components/ui/floating-nav"

const items = [
  { value: "home", label: "Home", icon: <HouseIcon />, href: "/" },
  { value: "saved", label: "Saved", icon: <BookmarkIcon />, href: "/saved" },
  { value: "profile", label: "Profile", icon: <UserIcon />, href: "/profile" },
]

export function AppNav({ pathname }: { pathname: string }) {
  return <FloatingNav items={items} value={pathname.split("/")[1] || "home"} />
}
```

Give every item a `label`, even with `labels="active"`. It's the item's name
for screen readers, and the label the current item shows.

</ExhibitCode>
<ExhibitCode label="Props">

| Prop            | Type                                         | Default     | Description                                                                                                         |
| --------------- | -------------------------------------------- | ----------- | ------------------------------------------------------------------------------------------------------------------- |
| `items`         | `FloatingNavItem[]`                          |             | Destinations, left to right. Three to five read best.                                                               |
| `value`         | `string`                                     |             | The current item, when controlled.                                                                                  |
| `defaultValue`  | `string`                                     |             | The current item on first render, when uncontrolled.                                                                |
| `onValueChange` | `(value: string, event: MouseEvent) => void` |             | Fires on a press. Call `event.preventDefault()` on a link to route it yourself.                                     |
| `labels`        | `"active" \| "always"`                       | `"active"`  | Only the current item's label, or every label under its icon.                                                       |
| `size`          | `"sm" \| "default"`                          | `"default"` | `sm` gives 36px items and 16px icons instead of 44px and 20px.                                                      |
| `variant`       | `"default" \| "glass"`                       | `"default"` | `glass` is Apple's liquid glass: a clear bar that bends the page behind its edges, with a lens on the current item. |
| `position`      | `"fixed" \| "static"`                        | `"fixed"`   | Float at the bottom of the viewport, or sit in the flow.                                                            |
| `hideOnScroll`  | `boolean`                                    | `false`     | Slide away while the page scrolls down, and back when it scrolls up or takes focus.                                 |

```ts
type FloatingNavItem = {
  value: string
  label: string
  icon?: React.ReactNode // leave out for a text item
  href?: string // renders a link; without it, a button
}
```

</ExhibitCode>
</Exhibit>

## Examples

### Liquid glass

`variant="glass"` draws the bar as liquid glass. A lightly frosted, tinted
layer and a bright rim work in every browser. In Chromium the page behind the
rim also bends, through an SVG displacement filter sized to the bar; Safari and
Firefox keep the blur and rim. The current item sits under a glass lens that
overshoots a little as it lands, and the bar swells a touch under a finger.

Pressing the bar lifts the lens off it, the way iOS does as you change tabs:
it grows past the bar's edges, clears, and magnifies the item beneath with a
fringe of colour at its rim, then travels to the new item and settles back
into its tint. In Safari and Firefox it lifts and clears without the
magnifying. With reduced motion it stays put.

The glass bar doesn't clip, so the lens can lift past it, which also means it
can't scroll sideways the way the default bar does when its items outgrow the
screen. Keep a glass bar to items that fit, or switch to `size="sm"` on narrow
screens.

### Text items

Leave out an item's `icon` and it shows its label as text, always. Use it when
there are only two or three places and their names say more than icons.

<Exhibit of="floating-nav.TextItems" description="Three places, named rather than drawn.">
<ExhibitCode>

```tsx
<FloatingNav
  size="sm"
  items={[
    { value: "home", label: "Home" },
    { value: "explore", label: "Explore" },
    { value: "saved", label: "Saved" },
  ]}
/>
```

</ExhibitCode>

### With your router

Items with an `href` render as links. `onValueChange` hands over the click, so
an app can call `event.preventDefault()` and route it itself.

<Exhibit of="floating-nav.ControlledLinks" description="Tap an item. The page title follows without a reload.">
<ExhibitCode>

```tsx
const router = useRouter()

<FloatingNav
  items={items}
  value={current}
  onValueChange={(href, event) => {
    event.preventDefault()
    router.push(href)
  }}
/>
```

</ExhibitCode>
</Exhibit>

## Anatomy

A nav landmark holding a pill. Each item is a link or a button, with an icon,
a label and, on the current one, the fill behind it. A text item has no icon.

<Exhibit

<ExhibitCode label="Structure">

```text
FloatingNav             floating-nav            (the nav landmark)
└─ list                 floating-nav-list       (the pill; slides out when hidden)
   ├─ glass             floating-nav-glass      (variant="glass"; the surface under the items)
   └─ item              floating-nav-item       (a link or button per destination)
      ├─ indicator                              (the current item only)
      ├─ lens           floating-nav-lens       (in place of the indicator with glass)

      └─ label
```

## Guidelines

## Accessibility

Every item is a plain link or button in tab order, so the bar works from the
keyboard without anything to learn.

| Key              | Does                                     |
| ---------------- | ---------------------------------------- |
| <Kbd>Tab</Kbd>   | Moves between the items                  |
| <Kbd>↵</Kbd>     | Goes to the item's destination           |
| <Kbd>Space</Kbd> | Goes to the destination of a button item |

<UsageGuidelines
  guidelines={[
    <>
      The root is a <code>nav</code> landmark, named Main unless you pass{" "}
      <code>aria-label</code>. Name it when a page has more than one.
    </>,
    <>
      The current item carries <code>aria-current="page"</code> when it's a
      link, or <code>aria-current="true"</code> when it's a button. Hidden
      labels stay in the DOM, so every item keeps its name.
    </>,
    "A hidden bar takes no taps or clicks, so it can't catch one meant for the page beneath. Its items stay in the tab order, and tabbing into it brings it back.",
    "Glass shows the page through it, so its labels' contrast depends on what scrolls beneath. Use it over images and media, and the default bar over dense text.",
    'Every item is at least 44px square, or 36px with size="sm", well above the 24px minimum target.',
    "With reduced motion, the indicator and the bar move without animating.",
  ]}
