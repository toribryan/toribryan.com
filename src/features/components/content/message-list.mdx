A conversation, with each person's messages grouped under their name. The
whole list is one Tab stop.

<Exhibit

<ExhibitCode label="Install">

```bash
npx shadcn@latest add https://fibo.toribryan.com/r/message-list.json
```

package.

</ExhibitCode>
<ExhibitCode label="Usage">

```tsx
import { MessageList, type ChatMessage } from "@/components/ui/message-list"

export function Channel({ messages }: { messages: ChatMessage[] }) {
  return (
    <div className="h-96 overflow-y-auto">
      <MessageList messages={messages} aria-label="#design" />
    </div>
  )
}
```

Pass the whole conversation, oldest first. Grouping looks at each message's
neighbours, so a list that only holds the rows on screen would start a new
group at the top of every scroll. If you virtualize, call `groupMessages` on
the full list and render from its result.

</ExhibitCode>
<ExhibitCode label="Props">

| Prop            | Type                          | Default      | Description                                                                                                  |
| --------------- | ----------------------------- | ------------ | ------------------------------------------------------------------------------------------------------------ |
| `messages`      | `ChatMessage[]`               |              | The conversation, oldest first.                                                                              |
| `windowMinutes` | `number`                      | `5`          | Minutes a group stays open.                                                                                  |
| `windowFrom`    | `"previous" \| "first"`       | `"previous"` | Measure the window from the previous message (rolling) or the group's first (fixed).                         |
| `unreadFrom`    | `string`                      |              | The first unread message. Freeze it when the conversation opens, so the divider stays put while people read. |
| `dividers`      | `Record<string, string>`      |              | Labels for dividers above messages, keyed by message id. Each one also breaks the group.                     |
| `headingLevel`  | `2 \| 3 \| 4 \| 5 \| 6`       | `3`          | The level of each group's heading.                                                                           |
| `locale`        | `string`                      | `"en"`       | Locale for times and dates.                                                                                  |
| `strings`       | `Partial<MessageListStrings>` |              | Copy for screen readers and deleted messages. Swap it to translate.                                          |
| `empty`         | `ReactNode`                   |              | Shown in place of the conversation when there are no messages. `null` shows nothing.                         |

It also takes every prop of a `div`, except `children`.

```ts
type ChatMessage = {
  id: string
  author: { id: string; name: string; avatar?: string }
  sentAt: Date
  content: React.ReactNode
  kind?: "message" | "system" // system for events like someone joining
  deleted?: boolean // its content is replaced
  replyTo?: { id: string; name: string; text: string } // quoted above it
}
```

Freeze `unreadFrom` when the conversation opens, so the line stays where it
was while people read; clear it when they send a message, press Escape or mark
the conversation read. Pair it with fibo's Jump bar.

### Break rules

`groupMessages` checks these in order, and the first that holds is the
message's `breakReason`. The first message in the list is `start`.

| Rule       | A new group starts when                                      |
| ---------- | ------------------------------------------------------------ |
| `divider`  | the message has a divider above it                           |
| `day`      | the message is on a different day from the one before        |
| `system`   | this message or the one before is a system message           |
| `deleted`  | this message or the one before was deleted                   |
| `reply`    | the message is a reply                                       |
| `author`   | a different person sent it                                   |
| `identity` | the same person sent it under a new name or picture          |
| `window`   | more than `windowMinutes` have passed since the window began |

Each message also gets a `position` of `single`, `first`, `middle` or `last`,
rendered as `data-position`. Bubble layouts use it to square off the corners
where bubbles meet.

## Anatomy

A log of articles, one per message, with a labelled separator above any
message that starts a day, carries a divider or is the first unread. The first
message of a group carries the avatar and heading; later ones keep the time in
the gutter, shown on hover or focus.

```text
   ├─ reply              message-reply           (on a reply)
   ├─ heading            message-heading         (first message of a group)
   └─ content            message-content
```

## Accessibility

| Key                                           | Does                                                               |
| --------------------------------------------- | ------------------------------------------------------------------ |
| <Kbd>Tab</Kbd>                                | Moves onto the list, at the newest message or the last one focused |
| <KbdGroup><Kbd>↑</Kbd><Kbd>↓</Kbd></KbdGroup> | Moves to the previous or next message                              |
| <Kbd>Home</Kbd> or <Kbd>End</Kbd>             | Jumps to the first or last message                                 |
| <Kbd>↵</Kbd>                                  | Moves into the message, to its first control                       |
| <Kbd>Esc</Kbd>                                | Comes back out to the message                                      |

<UsageGuidelines
  guidelines={[
