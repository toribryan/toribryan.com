Formatted writing, with a toolbar and Markdown shortcuts. It runs on Tiptap.

<ExhibitCode label="Install">

```bash
npx shadcn@latest add https://fibo.toribryan.com/r/rich-text-editor.json
```

It installs fibo's Button, Input and Tooltip with it, the `@tiptap/react`,
`@tiptap/starter-kit` and `@tiptap/extensions` packages, and the
`--input-subtle`, `--ring-subtle` and `--destructive-ring` tokens. Rich text
editor and Data table are the two base parts that depend on a package beyond
Base UI, class-variance-authority and lucide-react.

</ExhibitCode>
<ExhibitCode label="Usage">

```tsx
import {
  RichTextEditor,
  type RichTextEditorTool,
} from "@/components/ui/rich-text-editor"

const tools: RichTextEditorTool[] = [
  "heading",
  "bold",
  "italic",
  "bullet",
  "link",
  "history",
]

export function ReleaseNote({ onSave }: { onSave: (html: string) => void }) {
  return (
    <div className="flex flex-col gap-2">
      <Label id="release-note-label">Release note</Label>
      <RichTextEditor
        aria-labelledby="release-note-label"
        defaultValue="<p>What changed, and who it affects.</p>"
        tools={tools}
        maxLength={2000}
        onChange={(html) => onSave(html)}
      />
    </div>
  )
}
```

A label's `for` can't point at the writing area, which is not a form control,
so name it with `aria-labelledby` and the label's `id`. `id`,
`aria-labelledby`, `aria-describedby` and `aria-invalid` all go on the writing
area, not the frame.

The editor owns the document once it mounts: pass `defaultValue` to start it
and read `onChange` to keep up. To clear or replace it, change its `key`, or
use the Tiptap editor that `onChange` hands you. Sanitise the HTML on the
server before you show it to anyone else.

</ExhibitCode>
<ExhibitCode label="Props">

| Prop               | Type                                     | Default              | Description                                                                                     |
| ------------------ | ---------------------------------------- | -------------------- | ----------------------------------------------------------------------------------------------- |
| `defaultValue`     | `string`                                 | `""`                 | The starting content, as HTML. Later changes are ignored.                                       |
| `onChange`         | `(html: string, editor: Editor) => void` |                      | Called on every edit with the document as HTML, or `""` when it's empty, and the Tiptap editor. |
| `placeholder`      | `string`                                 | `"Write something…"` | Shown in the empty writing area.                                                                |
| `maxLength`        | `number`                                 |                      | The most characters the document may hold. Typing and pasting stop there.                       |
| `minHeight`        | `number`                                 | `140`                | Minimum height of the writing area, in pixels.                                                  |
| `tools`            | `RichTextEditorTool[]`                   | every tool           | Which tools the toolbar shows, in its fixed order. Shortcuts for hidden tools still work.       |
| `editable`         | `boolean`                                | `true`               | False shows the document without a toolbar and takes no edits.                                  |
| `label`            | `string`                                 | `"Editor"`           | Accessible name of the writing area. Ignored when `aria-labelledby` is set.                     |
| `id`               | `string`                                 |                      | Id of the writing area, not the frame.                                                          |
| `aria-labelledby`  | `string`                                 |                      | Ids of elements that name the writing area, such as a visible label.                            |
| `aria-describedby` | `string`                                 |                      | Ids of elements that describe the writing area, such as a hint or an error.                     |
| `aria-invalid`     | `boolean`                                |                      | Marks the writing area invalid and draws the frame in the destructive color.                    |

It also takes every prop of a `div`, except `children`, which go on the frame.

```ts
type RichTextEditorTool =
  | "heading"
  | "bold"
  | "italic"
  | "strike"
  | "code"
  | "bullet"
  | "ordered"
  | "quote"
  | "link"
  | "history" // Undo and Redo
```

</ExhibitCode>
</Exhibit>

## Features

- Bold, italic, strikethrough, inline code, a heading, lists, quotes and links
  from the toolbar, a shortcut, or Markdown as you type (`## `, `- `, `1. `,
  `> `, backticks).
- One tab stop for the whole toolbar; arrows, Home and End move inside it, and
  each button says whether it's on.
- Links go in through a row under the toolbar, never a browser prompt.
- `maxLength` stops typing and pasting at the limit and counts down from 80%.
- In a narrow frame the toolbar stays one row and scrolls sideways, so the
  writing area doesn't drop below a second row of tools.

### Proposal reply

A reply box with a short toolbar and a limit. The visible label names the
writing area through `aria-labelledby` and the hint describes it through
`aria-describedby`. Sending clears it by remounting it with a new `key`.

## Anatomy

A frame around a toolbar, the writing area and an optional count. The link row
opens between the toolbar and the writing area while a link is being added,
and a hidden live region reads the count at thresholds.

<Exhibit
  of="rich-text-editor.Anatomy"
  title="The parts"
  description="A short toolbar over a note close to its limit."
>
<ExhibitCode label="Structure">

```text
RichTextEditor         rich-text-editor
├─ Toolbar             rich-text-editor-toolbar     (editable, with tools)
│  └─ Tool             rich-text-editor-tool        (one per button, with data-tool)
├─ Link row            rich-text-editor-link-row    (while adding a link)
├─ Content             rich-text-editor-content     (once mounted)
├─ Count               rich-text-editor-count       (with maxLength)
└─ Announcer           rich-text-editor-announcer   (visually hidden)
```

Before the editor mounts, as in server-rendered HTML, an empty box the size of
the writing area holds its place (`rich-text-editor-skeleton`), so the page
doesn't shift.

</ExhibitCode>
