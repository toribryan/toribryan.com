A field that opens a calendar. `DatePicker` picks one day and closes;
`DateRangePicker` picks a start and an end, with presets, and applies them
together. On a phone both open as a drawer from the bottom.

<ExhibitCode label="Install">

```bash
npx shadcn@latest add https://fibo.toribryan.com/r/date-picker.json
```

It installs fibo's Calendar, Button and Sheet with it, and `lib/dates.ts`.

</ExhibitCode>
<ExhibitCode label="Usage">

```tsx
import { DateRangePicker, type DateRange } from "@/components/ui/date-picker"

export function ReportPeriod() {
  const [range, setRange] = useState<DateRange | null>(null)
  return (
    <DateRangePicker
      label="Report period"
      value={range}
      onChange={setRange}
      maxDate={new Date()}
    />
  )
}
```

Give each picker a `label` that says what the dates are for. It names the
trigger and the panel, and the trigger reads it with the value.

</ExhibitCode>
<ExhibitCode label="Props">

Both pickers take:

| Prop             | Type                              | Default   | Description                                                                               |
| ---------------- | --------------------------------- | --------- | ----------------------------------------------------------------------------------------- |
| `label`          | `string`                          |           | Names the panel and titles the drawer; names the trigger too unless a FieldLabel does.    |
| `placeholder`    | `string`                          |           | Shown in the trigger while nothing is picked.                                             |
| `type`           | `"auto" \| "popover" \| "drawer"` | `"auto"`  | A drawer below the sm breakpoint on `auto`; `popover` or `drawer` on every screen.        |
| `size`           | `"sm" \| "default"`               |           | Matches Input at 36 pixels tall, or 32 for dense forms.                                   |
| `minDate`        | `Date \| null`                    |           | The earliest day that can be picked.                                                      |
| `maxDate`        | `Date \| null`                    |           | The latest day that can be picked.                                                        |
| `isDateDisabled` | `(date: Date) => boolean`         |           | Return true for a day that can't be picked, such as a weekend.                            |
| `weekStartsOn`   | `0 \| 1`                          | `0`       | The first column of the calendar: 0 for Sunday, 1 for Monday.                             |
| `locale`         | `string`                          | `"en-US"` | A BCP 47 locale for the calendar and the formatted value.                                 |
| `open`           | `boolean`                         |           | Whether the panel is open, when you control it.                                           |
| `defaultOpen`    | `boolean`                         | `false`   | Opens the panel on first render, when the picker keeps its own state.                     |
| `onOpenChange`   | `(open: boolean) => void`         |           | Called when the panel opens or closes.                                                    |
| `container`      | `HTMLElement`                     | body      | The element the panel portals into.                                                       |
| `modal`          | `boolean`                         | `true`    | Traps focus, blocks the page and moves focus to the calendar. Turn off to show it inline. |

`DatePicker` adds:

| Prop           | Type                   | Default | Description                                      |
| -------------- | ---------------------- | ------- | ------------------------------------------------ |
| `value`        | `Date \| null`         |         | The picked day, when you control it.             |
| `defaultValue` | `Date \| null`         | `null`  | The picked day at first.                         |
| `onChange`     | `(date: Date) => void` |         | Called with the day as soon as it's picked.      |
| `presets`      | `DatePreset[]`         | `[]`    | Shortcuts beside the calendar, such as Tomorrow. |

`DateRangePicker` adds:

| Prop           | Type                         | Default                   | Description                                                           |
| -------------- | ---------------------------- | ------------------------- | --------------------------------------------------------------------- |
| `value`        | `DateRange \| null`          |                           | The applied range, when you control it.                               |
| `defaultValue` | `DateRange \| null`          | `null`                    | The applied range at first.                                           |
| `onChange`     | `(range: DateRange) => void` |                           | Called with the range when Apply is pressed.                          |
| `presets`      | `DateRangePreset[]`          | `defaultDateRangePresets` | Shortcuts beside the calendar. Pass an empty array to leave them out. |
| `months`       | `1 \| 2`                     | `2`                       | Months side by side in the popover; one below md. The drawer scrolls. |

Both also take the props of a `button`, for the trigger. Presets are a label
and a function of today:

```ts
type DateRangePreset = {
  label: string
  range: (today: Date) => { from: Date; to: Date }
}

type DatePreset = {
  label: string
  date: (today: Date) => Date
}
```

`defaultDatePresets` and `defaultDateRangePresets` are exported too.

## Features

- `DatePicker` picks as soon as a day is chosen. Presets such as Tomorrow are
  there when you pass them.
- `DateRangePicker` keeps a draft: two picks, a live preview between them, the
  range and its length in the footer, then Apply. Cancel and Escape leave the
  value as it was.
- Presets are functions of today, so "Last 7 days" stays right tomorrow.
  They're clamped to `minDate` and `maxDate`, and turned off when none of
  their range is allowed.
- Below the `sm` breakpoint the panel is a drawer: presets in a chip row,
  months in one vertical scroll with 44 pixel days, Apply at the bottom.
  `type` forces either.

## Which layout appears

| Screen            | DatePicker                                                                                                                   | DateRangePicker                                                                                                    |
| ----------------- | ---------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------ |
| sm and up (640px) | Popover below the trigger: an optional preset rail and one month. A pick closes it.                                          | Popover: preset rail, two months (one below md, 768px), and a footer with the range, its length, Cancel and Apply. |
| Below sm          | Drawer from the bottom: handle, the label as title with Cancel, chip row, and months in a vertical scroll. A pick closes it. | The same drawer, with a footer of the range, its length and a full-width Apply.                                    |

## Layout and spacing

| Part        | Size                                   | Spacing                                             | Tokens                                                                                     |
| ----------- | -------------------------------------- | --------------------------------------------------- | ------------------------------------------------------------------------------------------ |
| Trigger     | 36px tall, or 32 at sm; hugs its value | 12px sides, 8px between icon, value and chevron     | `input-subtle` fill, `input` border, `radius-sm`; `muted-foreground` placeholder and icons |
| Popover     | Hugs the calendar and rail             | 12px around the calendar                            | `popover` fill, `border`, `radius-xl`, large shadow                                        |
| Preset rail | 144px wide; 32px rows                  | 8px padding, 2px between rows                       | Ghost buttons; the active one on `muted`. A `border` rule on its right                     |
| Day         | 36px circle; 44px in the drawer        | No gap, so the range bar runs on                    | Ends on `primary` with `primary-foreground`; the bar on `muted`; today bold with a dot     |
| Footer      | Full width                             | 12px sides, 10px top and bottom; 16px in the drawer | `border` rule above; the count in `muted-foreground`                                       |
| Drawer      | 85% of the screen's height             | 16px sides; 4×40px handle                           | `background` fill, `border` top, `radius-xl` top corners                                   |

## Anatomy

The trigger is the only element in the page until it opens. The panel is a
popover from it, or a drawer on a phone, and holds a Calendar.

<ExhibitCode label="Structure">

```text
DatePicker / DateRangePicker   date-picker / date-range-picker
├─ value                       date-picker-value
├─ popup                       date-picker-popup         (sm and up)
│  ├─ presets                  date-picker-presets       (when there are any)
│  │  └─ preset                date-picker-preset
│  ├─ Calendar                 calendar
│  └─ footer                   date-picker-footer        (range only)
│     ├─ summary               date-picker-summary
│     ├─ count                 date-picker-count
│     ├─ Cancel                date-picker-cancel
│     └─ Apply                 date-picker-apply
└─ drawer                      date-picker-drawer        (below sm)
   ├─ handle                   date-picker-handle
   ├─ title                    sheet-title               (the label)
   ├─ Cancel                   date-picker-close
   ├─ presets                  date-picker-presets       (a chip row)
   ├─ Calendar                 calendar                  (scroll type, large)
   └─ footer                   date-picker-footer        (range only)
```

## Guidelines

<UsageGuidelines
  guidelines={[
    "Use DatePicker for one day, such as a due date, and DateRangePicker for a span, such as a report period or a stay. Don't use two DatePickers for a range.",
    "Offer presets for the ranges people pick most. The defaults suit reports; a booking flow wants This weekend or Next week.",
    "Bound the calendar to what's allowed rather than validating after Apply.",
