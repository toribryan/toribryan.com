A jump bar takes people somewhere else in a conversation: up to the messages
they haven't read, down to ones that arrived while they were scrolled up, or
back to the present from history. Counts stop at 99+ on screen, with the full
number after them for screen readers.

<ExhibitCode label="Usage">

```tsx
import { useState } from "react"

import { JumpBar, jumpTo, useAtBottom } from "@/components/ui/jump-bar"
import { MessageList, type ChatMessage } from "@/components/ui/message-list"

export function Channel({
  messages,
  unreadFrom,
  newBelow,
}: {
  messages: ChatMessage[]
  unreadFrom?: string
  newBelow: number
}) {
  const [scroller, setScroller] = useState<HTMLDivElement | null>(null)
  const atBottom = useAtBottom(scroller)

  function jumpToPresent() {
    const last = scroller?.querySelector<HTMLElement>(
      '[data-slot="message"]:last-of-type'
    )
    if (last) jumpTo(last, { container: scroller, block: "end" })
  }

  return (
    <div className="relative">
      <div ref={setScroller} className="h-96 overflow-y-auto">
        <MessageList messages={messages} unreadFrom={unreadFrom} />
      </div>
      {newBelow > 0 && !atBottom ? (
        <JumpBar type="new-below" count={newBelow} onJump={jumpToPresent} />
      ) : null}
    </div>
  )
}
```

The bars position themselves, so put them inside a `relative` wrapper around
the scroll container, not inside the container itself.

</ExhibitCode>
<ExhibitCode label="Props">

| Prop         | Type                                         | Default | Description                                                            |
| ------------ | -------------------------------------------- | ------- | ---------------------------------------------------------------------- |
| `type`       | `"unread-above" \| "new-below" \| "history"` |         | Which bar: unread messages above, new messages below, or history.      |
| `count`      | `number`                                     | `0`     | How many unread or new messages. Shown up to 99+, read out in full.    |
| `since`      | `Date`                                       |         | When the unread messages begin, for `unread-above`.                    |
| `onJump`     | `() => void`                                 |         | Jumps to the first unread message, the newest message, or the present. |
| `onMarkRead` | `() => void`                                 |         | Marks the conversation read, for `unread-above`.                       |
| `locale`     | `string`                                     | `"en"`  | Locale for the count and time.                                         |
| `strings`    | `Partial<JumpBarStrings>`                    |         | The bar's copy. Swap it to translate.                                  |

It also takes every prop of a `div`, except `children`.

```ts
type JumpBarStrings = {
  // shown is the count as displayed, capped at 99+; since is empty without a time
  unreadAbove: (count: number, shown: string, since: string) => string
  newBelow: (count: number, shown: string) => string
  history: string
  markRead: string
  jumpToPresent: string
}
```

`jumpTo(target, { container, block })` scrolls `target` into view and
focuses it. `useAtBottom(element, threshold = 150)` returns whether `element`
is scrolled to within `threshold` pixels of its end.

</ExhibitCode>
</Exhibit>

## Anatomy

A positioned root that holds plain buttons. Unread above is a bar across the
top with a jump button and "Mark as read"; new below is a single pill; history
is a bar across the bottom with a line of text and "Jump to present".
