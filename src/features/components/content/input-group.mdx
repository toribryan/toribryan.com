An input with an icon, text, a key or a button beside it, drawn as one field.

<Exhibit
  of="input-group.Default"
  title="Input group"
  description="Press the icon. Focus goes to the input."
>
<ExhibitCode label="Install">

```bash
npx shadcn@latest add https://fibo.toribryan.com/r/input-group.json
```

It brings fibo's `field-size` helper, which lets a Field or FieldGroup set
the group's size. Nothing else to install.

</ExhibitCode>
<ExhibitCode label="Usage">

```tsx
import { SearchIcon } from "lucide-react"

import {
  InputGroup,
  InputGroupAddon,
  InputGroupInput,
} from "@/components/ui/input-group"

export function Search() {
  return (
    <InputGroup>
      <InputGroupAddon>
        <SearchIcon aria-hidden="true" />
      </InputGroupAddon>
      <InputGroupInput type="search" aria-label="Search" />
    </InputGroup>
  )
}
```

Put the label outside the group, in a FieldLabel or `aria-label`. An icon
in an addon is decoration, not a name.

</ExhibitCode>
<ExhibitCode label="Props">

**InputGroup**

| Prop      | Type                   | Default                     | Description                                                        |
| --------- | ---------------------- | --------------------------- | ------------------------------------------------------------------ |
| `variant` | `"default" \| "ghost"` | `"default"`                 | `ghost` drops the border, fill and ring, for a search in a menu.   |
| `size`    | `"sm" \| "default"`    | The Field's, or `"default"` | Height of the group. Inside a Field or FieldGroup it takes theirs. |

**InputGroupAddon**

| Prop    | Type                             | Default          | Description                                |
| ------- | -------------------------------- | ---------------- | ------------------------------------------ |
| `align` | `"inline-start" \| "inline-end"` | `"inline-start"` | Which side of the input the addon sits on. |

**InputGroupInput** takes every prop of an `input`, plus `render` to swap in
another input, such as an Autocomplete's, and keep the look. The group and
the addon take every prop of a `div`.

</ExhibitCode>
</Exhibit>

## Anatomy

A group that draws the field, with an addon on either side of a borderless
input.

<Exhibit of="input-group.Anatomy" title="The field" description="A search with a leading icon.">
<ExhibitCode label="Structure">

```text
InputGroup              input-group           (draws the border, ring and invalid state)
├─ InputGroupAddon      input-group-addon     (an icon, text or button, at the start or end)
└─ InputGroupInput      input-group-control   (the input, with no border of its own)
```

</ExhibitCode>

## Guidelines

<UsageGuidelines
  guidelines={[
    "One addon on each side at most. More reads as a toolbar, not a field.",
    "Use a leading icon only when it says what the field is for, such as search or a handle's @.",
    "Use the ghost variant only where the surface around it marks the field, such as a popup's header.",
  ]}
/>
