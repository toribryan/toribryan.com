AuthorProof asks the question that ultimately better informs the verdict. On
submission, it generates a personalized comprehension quiz from the student's own
writing, in the submission's own language. The result surfaces as a score badge
inside SpeedGrader, where instructors already work, with a link out to the full
session for anyone who wants to dig deeper.

![How a submission becomes a comprehension quiz: content is extracted, a Canvas quiz is generated and assigned, the student is notified and completes it, and AuthorProof returns a report card](/case-studies/author-proof-flow.webp)

I led this end-to-end on a 4–6 week timeline from concept to production by
delivering design specs through prototypes built using HTML/CSS/Vanilla JS to the
engineering team. Surfaces included the LMS-embedded quiz-settings panel, the
AI-generated questions model, the student flow and notification system, and the
SpeedGrader results pathway.

Throughout, the product had to read as **confidence, not verdict**. Putting more
weight in evidence for a human conversation, never an automated judgment.
