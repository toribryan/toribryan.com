## Foundations

### Color

Three tiers, same as the rest of the practice: primitives never reach a
component, semantics do the routing, component tokens are the only thing a
component file may name.

```json title="tokens/color.json"
{
  "primitive": {
    "neutral-50": "#fafafa",
    "neutral-900": "#171717",
    "brand-500": "#000000",
    "brand-600": "#000000"
  },
  "semantic": {
    "ink": "{primitive.neutral-900}",
    "surface": "{primitive.neutral-50}",
    "accent": "{primitive.brand-500}",
    "accent-hover": "{primitive.brand-600}"
  },
  "component": {
    "button-bg": "{semantic.accent}",
    "button-bg-hover": "{semantic.accent-hover}",
    "button-fg": "{semantic.surface}"
  }
}
```

### Spacing

4px base unit. Steps: 4, 8, 12, 16, 24, 32, 48, 64. No half-steps — if a layout
needs 14px, the layout is wrong.

## Component contract

Every component published here ships with the same four things. A component
missing any of them isn't published, it's just drawn.

<Steps>

<Step>**Token map** — every visual property bound to a component token, no raw values.</Step>

<Step>**States** — default, hover, active, focus-visible, disabled, loading where it applies.</Step>

<Step>**Props table** — name, type, default, required. Generated, not hand-written.</Step>

<Step>**Code Connect** — the Figma component linked to its implementation, so the handoff has no translation layer.</Step>

</Steps>
